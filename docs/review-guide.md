# 初学者审查指南

Paper2Paper的记录是为了让用户能够检查AI，而不是让用户阅读更多术语。

## 审查候选路线

逐条问：

1. 我能用一句话复述问题吗？
2. 相比锚点到底改了什么？
3. 比较、结局和统计单位是否明确？
4. 什么结果会使路线失败？
5. 是否有更简单的路线能回答同一问题？

## 审查数据

- 报告的是患者数还是细胞数？
- 必需字段是否在实际下载文件中出现？
- discovery和validation是否共享患者？
- 公开链接是否真正可下载？
- 数据缺失会删除哪个claim或Figure？

## 审查代码

- 代码对应哪个具体模块？
- 版本、许可、环境和入口是否固定？
- 是否在目标环境运行过，而不是只看过README？
- smoke test使用了什么真实输入，生成了什么输出？
- AI重建部分有哪些donor和测试？

## 审查Figure

- 每幅主图服务哪个claim？
- 数据和代码依赖是否已经验证？
- source table和验收条件是什么？
- 删除这幅图是否影响中心论文故事？

## 审查路线选择

优先选择：

- 数据真实可取；
- 代码已运行或仅需有限重建；
- 最低主图完整；
- 科学设计清楚；
- 初学者能理解并复查；
- 非实质重复发表。

不要因为期刊档次想象、热门术语或分析数量更多而选择路线。

## 用户必须亲自批准

- 正式路线；
- 中心claim和claim ceiling；
- 放弃不可逆数据机会；
- 看过结果后的reroute；
- 最终稿件和发布。
