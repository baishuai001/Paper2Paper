# Formal manuscript projects

This directory contains only user-approved routes promoted from completed
Paper2Paper Pilots. Do not create a manuscript project by copying a Pilot or by
changing a Pilot stage.

Create one with `paper2paper promote`. Each project must retain immutable
provenance to its source Pilot, route and passed Pilot runs, then freeze and
rerun its own formal analysis. Pilot outputs are evidence for the promotion
decision; they are not automatically accepted as manuscript results.

Formal projects prioritize the manuscript, Figures, source tables and review.
They do not expand the reusable platform unless a new, concrete blocker makes a
separate core or module change necessary.
