# 从锚点文献到目标论文的候选路线

这些路线不是从“换 marker、换细胞、换癌种”菜单机械生成，而是从锚点文献特有的框架资产、当前公开数据、代码可重建性、硬伤修复价值和截至 2026-08-07 的最近发表重叠共同产生。当前没有路线被用户批准为正式目标论文；`active` 只表示建议优先做可行性 spike，`selected_route_id` 仍为空。

## 1. 先排除最容易误入的方向

- **再做一个 SPP1+TAM signature**：锚点已经做肝转移 AUC 和预后；2025–2026 年又出现多个 CRLM 巨噬细胞/基质 signature。仅换算法或基因数很难避免实质重复，并且最容易重现 outcome leakage、cutoff 和伪外部验证问题。
- **泛癌 SPP1 巨噬细胞**：Bill 等 2023 年已经系统提出 CXCL9:SPP1 TAM polarity 及泛癌协调生态；泛癌扩容不等于新问题。
- **再证明 SPP1+TAM 与 CD8 耗竭、CAF 通信或泛化代谢串扰**：2023–2026 年已有 SPP1–CAF、SPP1–CD44/T-cell stress、mCAF–SPP1 TAM–T-cell niche、THBS1–SPP1 轨迹、tumor-derived SPP1–CAF CXCL12，以及 SPP1+TAM–SLC6A20+ epithelial metabolic crosstalk 等工作。没有细胞来源、设计、质量控制或因果层面的明确新增，很容易重复。
- **直接把癌种换成胃癌或另一个癌种**：这不是被原则禁止，而是当前尚未有一组通过患者身份、转移部位、空间、结局和代码合同核验的数据。仅因为“可以换癌种”就先定题，会让偶然找到的数据反过来改写问题。

## 3. 为什么当前优先 SPP-R01

SPP-R01 不是因为它“最创新”，而是当前创新性、科学性、可行性和初学者负担的平衡最好：

1. 它珍惜锚点最独特的一段框架——TAM 代谢异质性和组织空间差异，而不是只保留一个 SPP1 marker。
2. 它把锚点最明显的潜在硬伤（`MT-CO1` 与线粒体 QC 循环、`ATP5F1E` 代谢命名矛盾）转化为可检验的目标论文问题。
3. 核心结果可以在下载全部百万细胞前，用 `GSE164522` 的一个可追溯处理后矩阵做 1–2 周 spike：去除 mt genes、供体级建模、阈值敏感性、程序稳定性。
4. 如果失败，失败原因清楚：亚型是技术/组织伪影或没有跨队列稳定性；可以及时停止，而不是继续堆 Figure。
5. 如果成功，目标论文不是“重复锚点”，而是给出一个经过 QC、供体和独立队列约束的多基因代谢状态，并明确其空间和主张边界。
6. 它的现实目标是常规领域论文或方法严谨的转化生信论文，不是假设能够达到 CNS 级别。
7. 2026 年已出现公开代码的 CRC SPP1+TAM 代谢串扰论文，因此 R01 只能保留为**有条件的 feasibility spike**：如果最终问题退化成“SPP1+TAM 有代谢改变、空间共定位或可做预后模型”，立即停止；只有锚点 `ATP5F1E/MT-CO1` 构念的预设压力测试、供体级修复和 CRLM 独立验证共同形成非重复主张时才继续。

## 4. SPP-R01 的最小主 Figure 闭环

1. **Figure 1：数据身份与复现问题**——患者/样本/组织/治疗 manifest；各队列内巨噬细胞识别；禁止用细胞数替代患者数。
2. **Figure 2：锚点亚型压力测试**——原 `ATP5F1E/MT-CO1` 分型与 pct.mt、nUMI、tissue、study 的关系；去除 mt genes 和 donor-aware 后是否保留。
3. **Figure 3：多基因程序重建**——在 discovery 内锁定候选程序，在独立队列 reference map/pseudobulk 验证；报告不成功状态。
4. **Figure 4：空间验证**——原发 CRC `GSE280315` 与 CRLM `GSE217414`；患者级定位、去卷积、ROI 和空间置换。
5. **Figure 5：免疫生态与边界**——锁定程序与 CD8/T-cell state 的患者级关联，以及 study、treatment、QC、cell-source、leave-one-study-out 敏感性。

bulk 生存只能在前五张图闭环且 signature 锁定后作为次级 Figure；不能为了凑临床意义而提前加入 outcome-guided 基因筛选。

## 5. 首个可行性 spike 的通过/停止标准

### 通过

- `GSE164522` 的处理后表达和 metadata 能唯一映射 donor、sample、tissue 和 cell；
- 至少有足够的 CRC、CLM、邻近肝供体，不把 cells 当 n；
- 去除所有 mt genes 后，候选代谢程序仍有多个核编码基因支持；
- pct.mt、nUMI、study/tissue 调整后效应没有完全消失；
- 在 `GSE225857` 或 `GSE178318` 中能得到同向的独立供体级信号；
- 最近文献没有已经发表同一多基因程序、相同比较和相同主张；尤其必须逐项排除 2025 脂代谢巨噬细胞论文和 2026 SPP1+TAM–上皮代谢串扰论文的 Figure/claim 重合。

### 停止或转向

- 患者/组织/治疗身份无法从 metadata 可靠恢复；
- 所谓状态几乎完全由 `MT-CO1`、线粒体比例或单一 study 决定；
- 两个独立队列方向不一致且不能由预先定义的治疗/平台差异解释；
- 必须看到 bulk 结局后才能挑出基因；
- 最终主张已由最近文献直接发表。

## 6. 当前不确定性

- 当前只是 metadata-level availability check，尚未达到 `sample_parsed`；不能说 SPP-R01 已可执行。
- `GSE164522` 的大矩阵、`GSE225857` 的聚合文件结构和 donor 字段需要真实下载解析。
- CRLM 最近文献非常拥挤；在锁定最终 program 和 Figure 前必须再做一次按“相同对象+比较+结局+数据+分析+claim”拆分的近邻审计。
- 如果用户拥有可靠湿实验合作，SPP-R04 的科学价值可能超过计算路线；在没有合作承诺前，不能用理想实验替代当前可执行方案。
