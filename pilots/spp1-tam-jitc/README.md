# SPP1+TAM JITC Pilot

This directory audits one real anchor paper, generates bounded candidate
routes and records minimal real-data evidence. It is a Pilot, not a formal
manuscript project. Begin with `anchor/audit.md`; its detailed Figure framework
and flaw-to-repair contracts are in `anchor/framework-assets.md` and
`anchor/repair-contracts.md`. Then use `paper2paper next .` to see evidence
gaps. Large data, credentials and copyrighted source PDFs stay outside Git.
