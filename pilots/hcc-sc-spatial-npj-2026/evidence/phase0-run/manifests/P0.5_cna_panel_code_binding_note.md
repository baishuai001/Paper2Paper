# P0.5 CNA 面板代码绑定说明

`P0.5_cna_panel_run_12_code.sha256` 在 12 样本任务仍运行且新版 batch 入口尚未上传时生成。
其中 `run_crc_cna_panel.py`、`run_crc_cna.R`、`prepare_crc_cna_inputs.py` 和
`summarize_crc_copykat.py` 的 hash 对应这次批处理使用的文件。

任务启动后，`summarize_crc_cna_concordance.py` 做过一次等价重构：把原有 cell identity join
和 evidence-class 逻辑提取为可复用函数，供最终面板汇总使用。因此清单中的该文件 hash 是
重构后的服务器文件，不应被当作每个运行中 Python 进程已加载源码的逐字节证明。

最终 P0.5 证据不依赖旧进程内的聚合表：CopyKAT/SCEVAN 原始预测、cell metadata 和各自
日志保持不变；面板完成后由当前固定版 `summarize_crc_cna_panel.py` 重新做完整 ID join、
类别校验和样本/状态汇总，并在其 receipt 中记录自己的 implementation SHA256。旧的逐样本
concordance 只作故障排查和交叉核对，不作为最终面板结论的唯一来源。
