# 配对 CNA 人工审查证据

本目录只保留可以公开审查的小型聚合表、冻结样本清单、代码与执行摘要。31 GB H5AD、
25 GB 完整 CNA 原始产物和逐细胞大矩阵留在云服务器，不进入 Git。

这些表支持的是表达推断 CNA 的两方法证据与配对可用性审查，不是 DNA 真值。正式 cNMF
在本证据包生成时尚未启动。

目录内容分工：

- 根目录的五张 review 表与 `execution-summary.json` 是人工审查所需的聚合结果；
- `manifests/` 保存运行前冻结的合同、43 样本面板、四个完整识别分片和代码绑定清单；
- `server-bound-wrappers/` 保存本次云服务器实际使用的监督脚本，供追溯失败与重启过程。

监督脚本包含本次服务器的绝对路径，不是可直接移植的通用入口。可复用的 Python 构建、运行、
合并和回归测试代码保存在 `../../code/phase_zero/`。
