## 一、这次试跑的性质

本规范只用于判断 CRC 路线是否值得继续，不是目标论文最终分析方案，也不表示 CRC 已经被选定。

这次试跑必须产生一个方向决定：

- **继续**：关键数据可解析，恶性程序有跨患者/数据集稳定性，空间与临床角色有现实补法；
- **缩减**：完整框架不可行，但某一段框架能够形成科学上成立的较小论文；
- **转向其他癌种**：CRC 的决定性数据或重复性问题无法修复；
- **停止该框架**：多个癌种均无法形成数据、代码和 Figure 闭环。

负结果也是有效结果，不能为了保留 CRC 路线而在看到结果后随意更换结局或故事。

## 二、保留、修复和替换的锚点资产

### 保留的分析框架

保留 NPJ HCC 的证据顺序：

> 多队列单细胞状态 → 恶性细胞程序 → 免疫/基质生态关系 → 空间检查 → 临床关联 → 计算扰动。

### 不直接保留的论文特异内容

- 不保留 HCC、HSP90B1 或原文的具体细胞状态名称；
- 不预先指定 CRC 靶点或 signature；
- 不要求目标论文复制锚点的全部 Figure；
- 不把 CRC-atlas 已发表的中性粒细胞主线改写成自己的主要发现。

### 必须落实的硬伤修复

- 冻结患者—样本—数据集—状态 manifest；
- 患者/供者是统计单位，细胞是子样本；
- cNMF 使用非负表达输入；
- 进行患者留出、数据集留出和多 seed 稳定性分析；
- 横断面数据不称为时间演化或谱系转换；
- 空间数据先做基因面板覆盖率检查；
- 治疗结局按具体队列、药物和时间点定义；
- Geneformer 使用患者隔离、标签置换和简单基线。

## 四、纳入与排除规则

### 纳入

- 能解析到患者、样本、研究和组织状态的细胞/样本；
- 具有非负表达矩阵的恶性上皮细胞；
- 关键比较中患者身份不重复或重复关系可以追踪；
- 空间样本有患者、切片、矩阵和坐标对应关系。

### 排除

- 患者或样本身份无法解析；
- 只能看到图表、无法取得分析输入；
- 状态标签完全依赖文件名推测且无法核实；
- cNMF 输入只有带负值的整合残差且无法取得非负表达；
- 目标空间程序的有效基因覆盖不足；
- 治疗药物、时间点或 response 定义不清。

所有排除都必须保留样本 ID、原因和时间，不能静默删除。

## 五、统计和生物学单位

- 主要统计单位：患者/供者；
- 次级单位：样本、切片、空间区域；
- 细胞和 spot：患者内部子样本，不提供独立患者数；
- 多个样本来自同一患者时，需采用患者层汇总、混合模型或患者内配对；
- 不以数百万细胞掩盖某个决定性状态只有少量患者。

## 六、主要比较、结局和协变量

- 改变合理 cNMF rank。

2. 保存文件版本、字节数、校验和、对象维度和字段清单；
3. 在筛选前输出完整患者/样本计数表；

5. cNMF 使用原始或明确的非负计数/表达矩阵；
6. 临床字段按队列报告缺失比例；
7. 不对治疗、response、患者 ID 或主要结局进行推测性填补；
8. 所有映射和缺失处理生成患者级 source table。

## 八、最小分析步骤

### 步骤 1：资源与环境预检

- 服务器可用空间、内存、CPU、GPU；
- Python/R 版本；
- H5AD backed 读取库；
- cNMF 和 Geneformer 版本；
- 预期下载量、峰值磁盘和临时文件位置。

### 步骤 2：设计表

生成患者×数据集×状态×部位×平台×治疗表，并检查：

- 状态是否与数据集完全重合；
- 是否存在桥接数据集；
- 各决定性状态患者数；
- 患者是否重复；
- 哪些状态只能作为探索性证据。

### 步骤 3：恶性上皮子集

输出：

- 每位患者/状态的恶性细胞数；
- 恶性判定来源；
- QC 前后计数；
- 非负矩阵检查；
- 子集对象和不可变 manifest。

### 步骤 4：小规模 cNMF

先使用有限 rank 和 seed 检验可运行性，不解释最终生物学。

输出：

- 程序 spectra 和 usage；
- rank/seed 稳定性；
- 患者贡献度；
- 留一患者/数据集结果；
- 失败日志和资源用量。

### 步骤 5：空间可测性

- 对每个暂时保留程序计算 Xenium 面板覆盖；
- 低覆盖程序不得生成“验证性”空间结论；
- 解析 GSE225857 的全转录组空间角色；
- 明确发现患者与验证患者是否重叠。

### 步骤 6：治疗队列合同

从 Table S1 的多个治疗队列中选择一个定义最清楚的候选，冻结药物、患者、时间点、response 和协变量。若没有任何队列合格，删除治疗主张，而不是合并不相容队列。

### 步骤 7：Geneformer smoke test

只有恶性源/目标状态经过患者和数据集留出后才进行：

- 固定模型版本和 token 字典；
- tokenizer 通过；
- 患者隔离；
- 至少两个 seed；
- 标签置换；
- 与差异表达或网络中心性等简单基线比较。

本轮只检验能否稳定运行，不将排名解释为治疗靶点。

## 十一、否证和结论上限

出现以下任一情况，应停止或缩减完整 CRC 路线：

- 状态与数据集完全重合且没有桥接/留出设计；
- 决定性状态患者不足；
- 恶性程序由单个患者或数据集驱动；
- 程序对 seed、rank 或 QC 极不稳定；
- 空间数据不能测量程序；
- GSE225857 患者/模态关系无法可靠重建；
- 找不到定义清楚的治疗队列；
- Geneformer 不稳定或不优于简单基线；
- 最近论文已经以相同数据、分析顺序和中心关系发表了实质相同结论；
- 服务器资源和初学者时间成本无法承受。

即使试跑通过，结论上限仍是“横断面状态关联、空间共现和计算候选优先级”。没有纵向/谱系和功能实验时，不称为真实演化、因果调控或已验证治疗靶点。
