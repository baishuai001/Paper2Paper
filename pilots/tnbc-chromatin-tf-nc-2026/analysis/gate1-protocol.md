# 一级闸门冻结协议：CRC免疫表型是否对应肿瘤上皮TF程序

冻结日期：2026-08-12  
冻结状态：在任何患者级TF结果生成前锁定  
执行位置：仅限云服务器 `/media/desk16/iy13202/projects/Paper2Paper`  

## 1. 决策问题

TNBC锚点首先证明患者亚群对应可重复的转录因子（TF）活性差异，再进入染色质过滤、药物
关联和体内验证。把框架迁移到CRC时，本闸门只回答：

> CRC-atlas论文定义的M型（巨噬细胞/单核细胞占优势）相对于非M型，是否在原发肿瘤的
> 作者标注Cancer cell中伴随稳定、患者级、跨数据集可复现的TF活性程序？

这是关联性闸门，不证明免疫细胞驱动肿瘤细胞，也不证明TF具有治疗因果性。中性粒细胞不
作为主分型变量，因为CRC论文在患者免疫分型时明确排除了多数数据集不能可靠捕获的
neutrophils。

## 2. 数据和统计单位

- 数据对象：CRC-atlas公开H5AD，必须匹配既有30,875,155,333-byte文件及SHA256收据。
- 暴露：H5AD中作者发布的 `immune_infiltration_type`；M与其余三型比较。
- 主分析细胞：具有作者免疫分型患者的原发肿瘤 `Cancer cell`。
- 统计单位：患者（`donor_id`），不是细胞、样本或spot。
- 同一患者多个原发样本合并为一个pseudobulk；样本和数据集冲突必须显式报告。
- 原始计数：只能使用整数、非负的 `raw/X`；标准化的 `.X` 禁止用于pseudobulk计数。
- 主阈值：每位患者至少50个Cancer cell；20、100、200作为预设敏感性阈值。
- 作者Cancer cell标签不是DNA验证恶性真值；这一限制进入最终claim ceiling。

## 3. 先验排除和数据审计

作者分型患者必须满足：

1. 每位患者只有一个非空免疫类型；
2. 分型所依据的原发肿瘤样本、治疗状态和细胞富集状态可追溯；
3. M与非M在主pseudobulk中分别至少15和30位患者；
4. 至少3个数据集同时含不少于3位M和3位非M患者；
5. 任何一个数据集不得贡献超过全部M患者的60%，否则判为数据集支配。

不满足1–4时结论为“不可判定/设计不足”，不包装成生物学阴性；满足数据条件但后续信号
失败时判“不通过”。

## 4. 作者分型的独立重建

使用作者细胞注释计算每位患者的免疫细胞组成：只计B、T、NK、plasma、mast和myeloid
细胞；排除Cancer、上皮、基质及neutrophil标签。保留论文的原始比例思路，同时增加CLR
组成数据敏感性。

- 数据集效应用训练数据内的线性残差化处理；
- 使用相关距离层次聚类（固定4类）及50个固定种子的K-means敏感性；
- 用调整Rand指数（ARI）比较重建结果与作者四型；
- 用leave-one-dataset-out分类检验M型能否由免疫组成在未见数据集中识别。

分型重建通过条件：

- M组的macrophage/monocyte总比例高于非M，双侧检验 `p < 0.01` 且Cliff's delta ≥ 0.33；
- 相关距离4类聚类与作者四型ARI ≥ 0.50；
- 50次K-means的中位ARI ≥ 0.40；
- leave-one-dataset-out M分类的总体AUROC ≥ 0.70。

## 5. TF活性计算

每位患者Cancer-cell原始计数求和，转换为 `log2(CPM + 1)`。保留至少10%患者达到CPM≥1的
基因。TF活性使用有符号、定向的人类CollecTRI边，零符号/冲突边排除，每个TF至少10个可测
靶基因。活动分数为逐患者、逐TF的单变量线性模型t统计量（ULM等价实现）。

使用两套冻结网络：

1. 完整CollecTRI有符号网络；
2. 以独立TCGA-COAD/READ原发肿瘤表达为背景，仅保留方向与调控符号一致、`|Spearman rho| ≥ 0.10`
   且边FDR≤0.10的CollecTRI边，形成CRC-context网络。

第二套是独立CRC表达背景过滤，不冒充ARACNe或染色质证据。

## 6. 统计模型与验证

主模型针对每个TF：

`z(TF activity) ~ M + dataset fixed effects + log10(Cancer-cell count + 1)`

扩展敏感性模型在覆盖率允许时加入MSI、CMS、解剖部位、分期、年龄和性别；类别缺失单列，
不以结果驱动选择协变量。报告调整效应、t、p及BH-FDR。

跨数据集复现采用：

- 每个同时含≥3位M和≥3位非M患者的数据集分别计算Hedges g；
- DerSimonian-Laird随机效应meta分析；
- leave-one-dataset-out（LODO）预测，每折只在训练集选绝对效应最大的10个TF、标准化并拟合
  class-weight balanced的L2 logistic regression；测试集在特征选择中不可见；
- 标签仅在数据集内部置换500次，计算无泄漏LODO AUROC的经验p值；
- 患者bootstrap 1,000次给出AUROC区间。

## 7. 冻结的通过/停止规则

只有以下六项全部满足，一级闸门才“通过”：

1. 数据审计满足第3节全部可判定条件；
2. 作者免疫分型满足第4节全部重建条件；
3. 完整CollecTRI主模型至少10个TF同时满足FDR≤0.05且绝对调整效应≥0.40；
4. 上述TF至少5个在随机效应meta中方向一致、meta FDR≤0.10、至少70%信息数据集同方向且
   `I² ≤ 75%`；
5. 至少5个主TF在CRC-context网络中方向相同且名义 `p < 0.05`；
6. 无泄漏LODO AUROC≥0.65、bootstrap 95%区间下限>0.55，且数据集内置换经验p≤0.05。

判定后立即停止：不运行ATAC、药物敏感性、治疗推荐、空间验证或湿实验推断。

- **通过**：可进入TNBC框架的下一层，但仍只能称“跨区室关联性TF程序”。
- **不通过**：数据条件充分，但六项中任一科学信号/复现条件失败；停止迁移框架。
- **不可判定**：数据身份、组别数量或跨数据集结构未达到预设最低条件；停止并报告缺失证据。
