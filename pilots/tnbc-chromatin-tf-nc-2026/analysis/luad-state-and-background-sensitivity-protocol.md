# LUAD 分子状态与共同背景敏感性分析冻结协议

## 1. 目的与边界

本分析解释为什么全 LUAD 主分析仅得到 3 个三系统 motif TF，并检验一种预先指定的替代解释：当前 22 个患者、13 个 PDX 和 19 条细胞系并不代表同一种 LUAD 肿瘤内在状态，而跨系统信号可能集中在 NKX2-1-high/TRU-like LUAD。

已经完成的“全 LUAD”Figure 2 主分析保持不变，不被本分析覆盖或重命名。本分析是状态审计、背景构建敏感性分析和预定义亚型再评估；它不能把事后筛出的样本冒充原始主分析。

## 2. 冻结的表达分类器

### 2.1 主分类器

- 使用 Wilkerson 等 2012 年公开的 506 基因 LUAD 最近质心分类器及作者仓库中的原始质心文件。
- 三个质心按已发表对应关系映射：`bronchioid = TRU`、`magnoid = proximal-proliferative (PP)`、`squamoid = proximal-inflammatory (PI)`。
- RNA-seq 输入使用 `log2(TPM + 1)`；若只有原始计数，先做样本内库大小标准化，再取 `log2(CPM + 1)`。
- 每个独立队列内逐基因减去该队列中位数；不跨平台合并表达强度。
- 对每个样本，计算其可用预测基因向量与三个冻结质心的 Pearson 相关；最大相关对应的类别是主分类结果。
- 至少 405/506（80%）预测基因可用才称为“可分类”。该阈值只控制输入完整性，不是生物学显著性阈值。
- 不用相关系数或第一、第二名差值排除样本。最高相关、次高相关、差值和可用基因数全部报告，作为连续置信度指标。

### 2.2 NKX2-1 肺泡谱系一致性检查

TRU 是主分类标签。NKX2-1-high 不取代 506 基因分类器，而作为预先指定、正交的一致性检查：

- 在每个独立 RNA 队列内计算 `NKX2-1, NAPSA, SFTPA1, SFTPA2, SFTPB, SFTPC` 的逐基因 z 分数；
- 肺泡谱系分数为可用基因 z 分数的均值，至少需要 4/6 个基因；
- `NKX2-1-high/TRU-concordant` 定义为：主分类为 TRU、NKX2-1 表达高于本 LUAD 队列中位数、且肺泡谱系分数大于 0；
- 该交集仅用于更严格的特异性分析。主亚型分析仍使用所有 TRU-like 样本，以免用人为表达切点替换已发表分类器。

## 3. 19 条细胞系与 13 个 PDX 的赋型顺序

1. 优先使用与 ATAC 模型同名、同来源或可核验同一模型的基线 bulk RNA-seq。
2. 细胞系主分类使用论文基线分析所用的 DRA001846：它包含 26 条未加药 LUAD 细胞系，并逐一覆盖现用 19 条 ATAC 细胞系。DRA006880–DRA006902 中与现用 ATAC 药扰面板配对的 DMSO RNA 作一致性检查；官方 manifest 显示 H1648 在该面板缺少 DMSO RNA，因此该敏感性集合为 18/19。DepMap/CCLE 作为第二个独立一致性检查。
3. PDX 只有在模型 ID 可逐一对应时才使用外部 RNA；同一研究的其他 PDX、同一患者但不同模型、或仅按突变类型相似的 RNA 均不能代替。
4. 不能因 EGFR 突变、腺癌病理名称或论文研究主题而直接判为 TRU。

## 4. PDX 缺少配对 RNA 时的冻结 ATAC 代理

若 13 个 PDX 没有可核验的配对 RNA，允许测试一个不在 PDX 上训练的代理：

- 在 TCGA-LUAD RNA–ATAC 配对样本中，以 RNA 的 506 基因分类结果为真值；
- 坐标使用已冻结的 GENCODE v47 protein-coding gene TSS；每个基因取所有已记录 TSS 的 ±2 kb union，重复 TSS 不得重复计数同一区间。无法映射 TSS 的预测基因排除，须保留至少 405/506 个基因；
- 坐标宇宙固定为 TCGA-LUAD 开放计数矩阵的 139,135 个共识区间。TCGA 每个肿瘤将两个技术重复原始计数合并后转为 CPM；每个基因汇总与其 TSS ±2 kb union 重叠的不重复共识区间 CPM，再取 `log2(sum(CPM) + 1)`；没有重叠区间时记为 0；
- 如代理通过，PDX 必须从去重、去小鼠污染后的基线 human ATAC fragment/BAM 在同一个 139,135 区间上重新计数和 CPM 标准化；CPM 的 library size 与 TCGA 开放矩阵保持同一定义，即该样本在这 139,135 个固定区间中的计数总和，不用全 BAM 比对数作分母。再使用上述同一汇总公式；不用各 PDX 样本自身的 peak 数、narrowPeak `signalValue` 或不同坐标集合代替；
- 对上述基因×样本 ATAC 特征在队列内逐基因中位数中心化；
- 用与三个冻结表达质心的 Pearson 相关最大值直接赋型，不在这批小样本中拟合自由参数；
- 通过条件同时为：TRU-vs-rest balanced accuracy ≥ 0.70，且 10,000 次标签置换的单侧 `p < 0.05`；
- 通过后才可把同一算法应用于 PDX 和细胞系 ATAC。未通过时，PDX 记录为 `UNRESOLVED_NO_MATCHED_RNA`，不得进入正式 TRU 三系统分析。

## 5. “是否同一状态”的报告方式

不另设人为的 80% 或多数票停止线。对两个模型系统分别报告 TRU/PP/PI/不可分类的确切计数、比例、Wilson 95% CI、分类熵和连续相关值。

- “全部属于同一状态”只有在所有可分类模型标签一致时成立；
- 只要同一系统出现两个或以上可重复识别的类别，就否定“全部 LUAD 共享同一状态”的字面假设；
- 是否值得做 TRU 子分析由三系统真实样本数、可用数据和原文半数样本规则共同决定，不用事后修改标签。

## 6. 共同背景构建敏感性分析

所有目标峰继续固定为 200 bp，保留每个样本全部可用峰，不把主分析压缩到相同峰数。hg38 canonical chromosome、ENCODE blacklist 和 FASTA 版本与已完成主分析相同。JASPAR 2024 与 CIS-BP 2.00 分开运行，并执行冻结的 JASPAR 优先、CIS-BP 回退规则。

共同背景预先限定为四种，不再根据结果增删：

| ID | 构建方式 | 角色 |
|---|---|---|
| B0 | TCGA-LUAD + TCGA-LUSC 癌种峰 + 三个 LUAD 系统全部目标峰的 union/merge/recenter | 已完成主分析，保持不变 |
| B1 | TCGA-LUAD 癌种峰 + 三个 LUAD 系统全部目标峰的 union/merge/recenter | 去除 LUSC 对共同背景的影响 |
| B2 | 仅 TCGA-LUAD 癌种峰，统一供三个系统使用 | 避免把待检验目标峰并入背景 |
| B3 | 仅三个 LUAD 系统全部目标峰的 union/merge/recenter | 检查外部 TCGA 峰集合的影响 |

四种背景均对所有系统复用同一个 BED。报告每种背景的峰数、宽度、GC、目标覆盖度、每个 TF/样本的 HOMER 结果及最终三系统 TF 数。B1–B3 都是敏感性结果，不能事后替换 B0 主结果。峰数匹配和 LUSC 背景继续只作既有敏感性/特异性分析。

## 7. TRU-like 预定义亚型再评估

分两层，避免把诊断分析冒充新发现：

1. **冻结候选诊断层**：在现有 31 个全 LUAD HC-TF 和现有逐样本 motif 结果中，仅使用预先赋型的 TRU-like 样本重新计算原文的“至少半数样本”支持率；患者、PDX、细胞系分别计算，不借用其他状态样本补足分母。
2. **正式发现层**：只有当患者、PDX、细胞系三端都能可靠识别 TRU-like 样本时，才另行冻结并重跑 `TRU vs non-TRU` 的 Figure 1 TF 发现，再把新发现的 TF 送入 Figure 2。诊断层不能被称为 TRU-specific TF discovery。

诊断层沿用 TNBC 原文式规则：各系统启动子在至少一半该亚型样本中开放；仅排除三个系统平均 TF 活性 NES 均小于 0 的 TF；HOMER 校正后 `p < 1e-5`，motif 在各系统至少一半该亚型样本中获得支持。样本数和整数阈值逐系统明示，不另设最少 TF 数或项目停止线。

## 8. 更优模型数据的检索和纳入标准

系统检索 GEO/SRA、BioStudies/ArrayExpress、ENCODE、dbGaP/EGA、论文补充材料和作者数据声明。候选必须逐项记录：

- 人 LUAD 真 PDX 或可核验 LUAD 细胞系；
- 未处理基线 bulk ATAC-seq（单细胞 ATAC 另列，不能直接混入）；
- 独立模型数，不把技术重复、传代或处理条件计作新模型；
- 原始 reads 或可复算的峰/信号文件；
- 峰质量/QC 指标；
- 同模型基线 RNA 或冻结分型所需的可核验状态元数据；
- 下载权限和稳定 accession。

候选先做 manifest 和质量审计，再决定是否用于替换或外部验证；不会因为结果更符合假设而纳入。
