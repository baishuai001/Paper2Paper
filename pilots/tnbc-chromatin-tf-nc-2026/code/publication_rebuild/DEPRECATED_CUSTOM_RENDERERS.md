# Deprecated custom plot renderers

The custom renderers in this directory are retained only for provenance and
are **not approved for manuscript figures**. They were superseded after the
TNBC CodeOcean capsule was confirmed to contain official plotting code.

Use `../official_port/` for all reproducible LUAD figure generation. Official
source hashes, permitted substitutions, unified diffs, unsupported panels and
manual-only panels are audited there.
