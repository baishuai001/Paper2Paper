# 真实锚点文献 Pilots

`pilots/` 中每个一级目录对应一篇真实锚点文献。Pilot 的主任务是把这篇文献的独特框架推进到明确判断，而不是证明整个 Paper2Paper 可靠。

每个 Pilot 交付：

- 锚点问题—证据—分析—Figure 框架和公开复现边界；
- 硬伤、仍可利用部分和目标论文修复方案；
- 候选目标论文路线及具体重复风险；
- 数据、代码和最低 Figure 合同；
- 最小真实运行、失败、结果、限制和下一步；
- AI 的首选/备选建议与用户决定；
- 真实执行暴露的 workflow 问题、当前修复和复验结果。

一个 Pilot 可以形成目标论文、保留为训练案例或停止。不同 Pilot 的数据、公式、cutoff 和预期结果互不继承；复用代码前必须重新核对输入、预处理、统计单位、许可、输出和 claim。

当前保留案例：

- `gastric-nrrs/`：胃癌神经相关八基因 NRRS 的限定公开数据重建。它是训练案例，不是新论文路线，也不代表其他论文类型。

双循环规则见 [docs/learning-loop.md](../docs/learning-loop.md)。
