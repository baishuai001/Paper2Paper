# Minimum execution spike

## Data

- [ ] Canonical URI and access state verified.
- [ ] Required metadata fields inspected.
- [ ] Representative file downloaded and parsed.
- [ ] Biological unit and cohort overlap verified.
- [ ] File size and checksum recorded when stable.

## Code

- [ ] Commit, tag, release, or package version fixed.
- [ ] License and reuse boundary recorded.
- [ ] Environment and noninteractive entrypoint documented.
- [ ] Installation completed in the target environment.
- [ ] Representative real-data smoke test passed.
- [ ] Hardcoded paths and private dependencies removed or documented.

## Figure

- [ ] Minimum main figures are listed.
- [ ] Every required figure maps to datasets and code modules.
- [ ] Source-table path and acceptance test are explicit.
- [ ] At least one representative output was generated.

## Publication overlap

- [ ] Search query and date recorded.
- [ ] Nearest paper compared across all seven dimensions.
- [ ] Distinguishability is concrete.
- [ ] No `duplicate` route proceeds.

## Approval

- [ ] Assessment fields derive P0.
- [ ] Human review is completed and linked to the route.
