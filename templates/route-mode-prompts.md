# Route-mode prompts

Generate all scientifically plausible lanes before ranking. “Not applicable”
is acceptable, but omission without explanation is not.

## Faithful reproduction

Can the anchor's central figures be regenerated from public inputs? Which
missing author decisions or private data prevent exact reproduction?

## Marker or gene substitution

Which marker could occupy the same analytical role? Is it measurable in the
same datasets, and does the resulting comparison remain biologically coherent?

## Gene-set substitution

Can the central program be replaced by a prespecified, reproducible gene set?
Is its definition independent of the outcome used for validation?

## Cell-type substitution

Which cell type can use the same single-cell/spatial evidence order? Are there
enough patients and validated annotations for patient-level inference?

## Cancer-type substitution

Which cancer provides comparable disease stages, outcomes, public cohorts, and
code-compatible platforms? Which anchor assumptions cease to hold?

## Pan-cancer extension

Are harmonized outcomes, covariates, tissue context, and independent cohorts
available? Will cancer types be analyzed as units rather than pooled samples?

## Signature construction

What is the frozen feature source, training procedure, coefficient formula,
internal validation, external validation, calibration, and leakage control?

## Combined substitution

Which changes form one coherent manuscript question? Does each additional axis
improve execution or scientific validity enough to justify its burden?
